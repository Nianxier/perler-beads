# 微信小程序提审发布指南

小程序端位于 `apps/miniprogram`（原生小程序，查看/跟拼/轻编辑）。
本指南覆盖从注册到发布的完整流程与常见驳回点。

## 一、注册 AppID（一次性）

1. 打开 [微信公众平台](https://mp.weixin.qq.com/) → 「立即注册」→ 小程序
2. 主体选择：
   - **个人主体**：免费、当天可用；不能开通支付、部分高级类目受限——本工具足够
   - 企业主体：需营业执照，认证 30 元/年
3. 注册完成后在「设置 → 基本设置」拿到 **AppID**

## 二、替换 AppID

用[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)打开
`apps/miniprogram` 目录 → 右上角「详情 → 基本信息」填入你的 AppID；
或直接改 `project.config.json` 里的 `"appid"` 字段。

## 三、类目与提审要点

- **服务类目**：建议「工具 → 效率/办公」或「生活服务 → 生活工具」（个人主体可选范围内）
- **页面提审注意**（对照我们的功能逐条自检）：
  | 检查项 | 我们的情况 |
  | --- | --- |
  | 用户隐私 | 图纸全部本地存储，不上传服务器、无登录、无收集信息 ✓ |
  | 支付/虚拟支付 | 无 ✓ |
  | 用户生成内容（UGC） | 无社区/发布功能，不涉及内容审核 ✓ |
  | 类目与功能一致 | 工具类：图纸查看/编辑/跟拼 ✓ |
  | 前置声明 | 若提审模板要求「用户生成图片」说明，写明「本地处理不上传」 |

## 四、发布流程

1. 开发者工具 → 「上传」→ 填版本号（如 1.0.0）与备注
2. 微信公众平台 → 「版本管理」→ 开发版本 → 「提交审核」
3. 审核通过（一般 1~3 天）→ 「发布」
4. 发布后微信搜索小程序名即可使用，也可生成小程序码分享

## 五、常见驳回与对策

| 驳回原因 | 对策 |
| --- | --- |
| 类目不符 | 改选「工具」类目；功能描述写「拼豆图纸查看与跟拼工具」 |
| 功能不完整/白屏 | 确认上传的是 `apps/miniprogram` 构建产物目录；真机预览自检 |
| 隐私协议缺失 | 设置→服务内容声明→用户隐私保护指引：声明「不收集用户信息」 |
| 涉及图片上传 | 如后续加图片功能，需补充「相册权限用途说明」 |

## 六、版本迭代

改代码 → 开发者工具上传新版本 → 提审 → 发布。旧版本自动保留可回退。
