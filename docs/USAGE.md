# 拼豆图纸软件 · 使用手册

电脑端网页 + 微信小程序，纯本地数据、JSON 文件互通、零后端。

## 电脑端（apps/web）

### 启动
- 开发模式：`node <pnpm.mjs> --filter @perler/web dev` → 浏览器打开 http://localhost:5173
- 产物模式：`node <pnpm.mjs> --filter @perler/web preview` → http://localhost:4173
- 注意：dist 不能用 file:// 双击打开（浏览器拦截 ES 模块），必须经小服务器托管

### 开始创作（首开向导）
打开页面即弹出三选一：
1. **图片转图纸**：可先设宽度、等比留边/拉伸铺满、是否抖动
2. **文字转图纸**：多行文字、加粗、宽度设定 → 像素豆字
3. **创建空白图纸**：自定宽高

工具栏最左「开始向导」可随时重开。

### 工具栏速查
| 区域 | 功能 |
| --- | --- |
| 工具 | 铅笔(B)、橡皮(E)、油漆桶(G)、取色(I) |
| 历史 | 撤销(Ctrl+Z)、重做(Ctrl+Y)；所有操作（含改大小/镜像/旋转）可撤销 |
| 视图 | 网格/色号开关、适应窗口、缩放＋－（滚轮缩放、右键/空格拖动平移） |
| 镜像旋转 | 镜像↔、镜像↕、旋转↻/↺ |
| 新建图纸 | 宽×高 + 新建空白（有内容时弹确认） |
| 调整大小 | 宽×高 + 对齐方式（左上/居中/右下），**保留已有内容** |
| 图片转图纸 | 宽度、等比/拉伸、抖动（Floyd-Steinberg，细节更细腻） |
| 导出 | 施工图 PNG（含用量图例）、分板导出（29/52 底板多张 PNG）、保存/打开 JSON、存/读草稿 |

### 色板
- 顶部下拉切换色卡：MARD 基础221 / 全套291 / COCO / 漫漫 / 盼盼 / 咪小窝
- 分区 chip（A 黄橙系…M 大地系）快速筛选；支持色号/HEX 搜索
- 换色卡会按相近颜色转换当前图纸（有确认提示）

### 导出说明
- **施工图 PNG**：逐格色号 + 每 5 格坐标 + 标题（尺寸/总豆数）+ 底部用量图例（色号×数量）
- **分板导出**：大图按 29×29 或 52×52 底板拆成多张，每张标注「第几行第几列、全局行列范围、共几块板」
- **JSON**：`perler-pattern` v1 格式，跨端互通与继续编辑用
- **用量 CSV**：色号/颜色/数量，Excel 可开

## 微信小程序（apps/miniprogram）

1. 微信开发者工具打开 `apps/miniprogram` 目录（appid 为 touristappid 体验版）
2. 电脑端「保存 JSON」→ 文件发到微信 → 小程序「从聊天文件导入图纸 JSON」
3. **图纸**页：查看施工图（双指缩放、单指拖动、网格/色号开关）
4. **跟拼**页：按用豆数逐色跟拼，当前色高亮其余变灰；「完成当前色」推进；进度自动保存，退出再进不丢
5. **用量**页：逐色号数量

## 常见问题

- **改宽高没反应？** 工具栏分两组：「新建空白」= 清空重来；「调整大小」= 保留内容变尺寸。改数字后要点对应按钮。
- **色卡怎么没有 264 全套 / 128 渐变？** 开源社区无此数据（已核查所有参考仓库），现有 221 基础 + 291 全套；有官方色卡照片可补录。
- **怎么分享给朋友？** 发 JSON 文件；对方电脑端「打开 JSON」或小程序导入即可。
- **数据会上传吗？** 不会。全部在浏览器/微信本地存储，无账号无服务器。
